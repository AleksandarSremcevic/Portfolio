# Portfolio Project

This is a portfolio website showcasing various design works, including logo designs, graphic designs, and website projects. The project features a modern layout with video backgrounds and smooth scrolling effects.

## Project Structure

- **src/**
  - `index.html`: Main structure of the portfolio website.
  - `index.js`: JavaScript functionality for the portfolio.
  - `index.css`: Styles for the portfolio website.

- `logo.png`: Brand logo image used in the header.

- `logo1.jpg`, `logo2.jpg`, `logo3.jpg`: Logo images displayed in the logo designs section.

- `graphic1.jpg`, `graphic2.jpg`, `graphic3.jpg`: Graphic images displayed in the graphic designs section.

- `web1.mp4`, `web2.mp4`: Video files displayed in the website projects section.

- `me.jpg`: Image displayed in the about me section.

## Features

- **Responsive Design**: The website is designed to be responsive and looks great on all devices.
- **Video Backgrounds**: Engaging video backgrounds in the header section.
- **Popup Menus**: Each design section includes a "See More" button that opens a popup menu displaying additional images.
- **Image Enlargement**: Users can click on images in the popup to view them in an enlarged format.
